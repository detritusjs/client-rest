# Detritus Client Rest
![npm](https://img.shields.io/npm/v/detritus-client-rest?style=flat-square)

A pure-TypeScript library for just Discord's REST API.

- [API Documentation](https://detritusjs.com/client-rest/)
- [npm](https://www.npmjs.com/package/detritus-client-rest)

## Installation

- `$ npm i detritus-client-rest@beta`
- `$ yarn add detritus-client-rest@beta`

The current version is published under npm's `beta` tag. `latest` is still the old 0.10.5.

It needs Node 22.19 or newer.
